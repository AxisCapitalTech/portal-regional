# Portal Regional — V5

Projeto privado de portal jornalístico regional em WordPress, com foco editorial em Arapongas, Londrina, Maringá e Apucarana, além de Paraná e Brasil.

**Estado:** homologação. O código-base V5 e os testes automatizados estão em preparação para importação. Nenhuma notícia é publicada automaticamente.

**Segurança editorial:** as pautas coletadas devem passar por revisão e aprovação humana antes da publicação. Os testes locais foram executados, mas a instalação WordPress/MariaDB hospedada ainda não foi validada.
